```md
## 2. Rủi ro và Cách giảm thiểu (Risks & Mitigations)
- **Rủi ro 1 (Lệch shape kích thước ảnh trong nhánh Up):** Khi kích thước đầu vào (Height/Width) lẻ hoặc không chia hết cho 16, tại nhánh Decoder kích thước Upsample có thể bị lệch 1 pixel so với Skip Connection từ Encoder, làm hàm `torch.cat` báo lỗi kích thước.
  - *Cách giảm thiểu:* Tại module `Up` trong `unet_parts.py`, tính chênh lệch chiều không gian `(diffY, diffX)` và sử dụng `F.pad` vào tensor được upsample để cân bằng kích thước hoàn hảo trước khi nối.
- **Rủi ro 2 (Overfitting nhanh / Data Imbalance):** Mask của ảnh y tế thường chứa rất ít pixel dương (mất cân bằng lớp).
  - *Cách giảm thiểu:* Bổ sung trọng số cấu hình loss (`CombinedLoss = BCE + Dice`), và kỹ thuật Data Augmentation mạnh mẽ như ElasticTransform.
- **Rủi ro 3 (Tràn VRAM trên GPU T4/L4):** Training ảnh to hoặc Batch size lớn.
  - *Cách giảm thiểu:* Tích hợp AMP (`torch.cuda.amp`), tuỳ chọn Gradient Checkpointing (`torch.utils.checkpoint`) bên trong `unet_model.py`.
- **Rủi ro 4 (Colab ngắt kết nối):**
  - *Cách giảm thiểu:* Tự động lưu `last.pth` sau mỗi epoch. Thiết lập hàm đọc resume state (optimizer, scheduler) ở đầu file `train.py`.
```

# Đặc tả Kỹ thuật (Technical Specification) - U-Net Baseline

Tài liệu này xác định quy chuẩn mã nguồn cho toàn bộ các module trong dự án.
*Quy định chung:* Sử dụng Python >= 3.10, PyTorch >= 2.0. Tất cả các public classes và functions bắt buộc phải có Type Hints và Docstring.

---

## 1. Module Mô hình (models/)

### 1.1 `models/unet_parts.py`
Chứa các thành phần cấu tạo (building blocks) cơ bản của U-Net.
*   **`class DoubleConv(nn.Module)`**
    *   *Init:* `(in_channels: int, out_channels: int, mid_channels: int = None)`
    *   *Mô tả:* Lớp chập kép bao gồm 2 lần chuỗi `Conv2d` (kernel=3, padding=1, bias=False) $\rightarrow$ `BatchNorm2d` $\rightarrow$ `ReLU(inplace=True)`. Nếu `mid_channels` là None, gán bằng `out_channels`.
*   **`class Down(nn.Module)`**
    *   *Init:* `(in_channels: int, out_channels: int)`
    *   *Mô tả:* Kết hợp `nn.MaxPool2d(2)` và `DoubleConv`.
*   **`class Up(nn.Module)`**
    *   *Init:* `(in_channels: int, out_channels: int, bilinear: bool = True)`
    *   *Mô tả:* Lớp giải mã (Decoder). Nếu `bilinear=True`, sử dụng `nn.Upsample(scale_factor=2, mode='bilinear', align_corners=True)` kết hợp với `DoubleConv`. Nếu `False`, dùng `nn.ConvTranspose2d(in_channels, in_channels // 2, kernel_size=2, stride=2)`.
    *   *Forward:* Nhận đầu vào `(x1: Tensor, x2: Tensor)` trong đó `x2` là skip connection. Trước khi `torch.cat`, tự động tính toán bù trừ không gian chiều cao/rộng và áp dụng `F.pad` để căn chỉnh shape chuẩn xác 100%.
*   **`class OutConv(nn.Module)`**
    *   *Init:* `(in_channels: int, out_channels: int)`
    *   *Mô tả:* `nn.Conv2d(in_channels, out_channels, kernel_size=1)`. Dùng ở lớp cuối cùng.

### 1.2 `models/unet_model.py`
*   **`class UNet(nn.Module)`**
    *   *Init:* `(n_channels: int, n_classes: int, bilinear: bool = False, base_channels: int = 64)`
    *   *Cấu trúc:* 
        *   Tầng vào `inc`: `DoubleConv(n_channels, base_channels)`
        *   Tầng xuống (`down1` -> `down4`): Kênh tăng dần `64 -> 128 -> 256 -> 512 -> 1024`. (Nếu `bilinear=True` thì tầng 4 chỉ tới `512` vì bước concat sẽ nhân đôi số kênh).
        *   Tầng lên (`up1` -> `up4`): Kênh giảm dần.
        *   Tầng ra `outc`: `OutConv(base_channels, n_classes)`.
    *   *Output:* Trả về Raw Logits của mạng, **KHÔNG** áp dụng `Sigmoid/Softmax` ở lớp cuối. Xử lý hàm kích hoạt sẽ nằm ở lớp Loss.
    *   *Đặc tả tính năng bổ sung:* Có hàm `init_weights()` với kỹ thuật Kaiming Normal. Hỗ trợ kích hoạt `torch.utils.checkpoint.checkpoint` trên các block nếu RAM yếu (dựa vào cờ tùy chọn).

## 2. Module Tiện ích (utils/)

### 2.1 `utils/dataset.py`
*   **`class SegmentationDataset(Dataset)`**
    *   *Khởi tạo:* `(root: str, split: str, transform: Callable = None, image_size: int = 256, n_classes: int = 1, mean: tuple = (0.5,), std: tuple = (0.5,))`
    *   *Logic:* Đọc danh sách file từ thư mục con `images/` và `masks/`. Gom cặp theo thuộc tính `stem` (tên file không lấy đuôi). Nếu phát hiện file ảnh mà không có mask tương ứng, raise Error cảnh báo mạnh.
    *   *Tiền xử lý:* Chuyển numpy/ảnh thành Tensor. Nếu n_classes == 1, trả về mask dạng FloatTensor shape `(1, H, W)` để dùng `BCEWithLogitsLoss`. Nếu n_classes > 1, trả mask LongTensor shape `(H, W)` để dùng `CrossEntropyLoss`.
*   **`def get_dataloaders(cfg: dict) -> Tuple[DataLoader, DataLoader, DataLoader]`**
    *   Dựa vào file config để nạp Dataset, cấu hình cho train_loader (`shuffle=True, drop_last=True`) và test/val loader.

### 2.2 `utils/transforms.py`
*   Gói bằng thư viện `Albumentations`.
*   **`get_train_transforms`**: Gồm ShiftScaleRotate, RandomRotate90, Horizontal/Vertical Flip, RandomBrightnessContrast. Mask sử dụng thuật toán nội suy `cv2.INTER_NEAREST` để không bị nát giá trị nhị phân.
*   **`get_val_transforms`**: Chỉ thực hiện thao tác Resize về kích thước chỉ định.

### 2.3 `utils/losses.py`
*   **`class DiceLoss`**: Tính Dice dựa trên dự đoán đã chạy qua qua `Sigmoid` (nếu n_classes=1) hoặc `Softmax` (n_classes>1). Hỗ trợ smoothing `eps=1e-6`.
*   **`class BCEWithLogitsLossWrapper`**: Bọc lại `nn.BCEWithLogitsLoss`.
*   **`class FocalLoss`**: Giúp tập trung học ở những vùng biên khối u khó dự đoán.
*   **`class CombinedLoss`**: Hàm nhận vào dict trọng số để cộng tuyến tính nhiều loại loss (Ví dụ: `0.5*BCE + 0.5*Dice`).

### 2.4 `utils/metrics.py`
*   Định nghĩa các hàm rời rạc nhận đầu vào là mảng Numpy hoặc Tensor: `calculate_iou`, `calculate_dice`, `calculate_hd95`.
*   **Lưu ý HD95**: Sử dụng `scipy.spatial.distance.directed_hausdorff` hoặc `medpy.metric.hd95`. Hàm bắt buộc phải có lệnh `try-except` chặn lỗi trường hợp mask Ground Truth rỗng (không có khối u), trong trường hợp đó quy ước trả về `NaN` hoặc `0.0` tùy cấu hình.

## 4. Các kịch bản chạy (Scripts)

### 4.1 `train.py`
*   *Mục đích:* Kịch bản vòng lặp chính.
*   *Tính năng:* Parse file YAML và parse command-line argument theo cặp key-value để ghi đè (override) tạm thời config.
*   Thiết lập tính năng cố định Seed (Determinism).
*   Đóng gói kiến trúc Trainer theo chuẩn: 1 hàm `train_epoch`, 1 hàm `validate_epoch`.
*   Xuất log ra màn hình Console (dùng `tqdm`) và ghi biểu đồ Tensorboard.
*   Lưu 2 file: `last.pth` (lưu cả optimizer state để resume) và `best.pth` (chỉ lưu weights có metric cao nhất).

### 4.2 `evaluate.py`
*   *Mục đích:* Dùng model đã huấn luyện (`best.pth`) ném vào tập Test để chốt số liệu.
*   *Tính năng:* Chạy 1 vòng qua Test Dataset (không tích lũy Gradient). Lưu lại một file `.csv` chứa điểm số Dice/IoU/HD95 của **từng tấm ảnh**, và dòng cuối hiển thị trung bình ± độ lệch chuẩn (mean ± std).

### 4.3 `predict.py`

```py
                iou = calculate_iou(p_i, t_i)

                    std = np.array(cfg["data"].get("std", [0.5, 0.5, 0.5]))

                    overlay[gt_mask] = [0, 255, 0]        # Green: GT

                    overlay[overlap] = [0, 255, 255]      # Yellow: Trùng khớp
```

```py
"""
unet_model.py
-------------
Kiến trúc hoàn chỉnh của mạng U-Net chuẩn (Ronneberger et al., 2015).
Đầu ra trả về raw logits (chưa qua activation).
Hỗ trợ:
- Kaiming Normal initialization
- Gradient checkpointing tùy chọn để tiết kiệm VRAM
- Factory function build_model(cfg)
"""

from typing import Dict, Any
import torch
import torch.nn as nn
from torch.utils.checkpoint import checkpoint

from .unet_parts import DoubleConv, Down, Up, OutConv


class UNet(nn.Module):
    """
    Kiến trúc U-Net chuẩn gồm 4 tầng Down và 4 tầng Up.

    Args:
        n_channels: Số kênh ảnh đầu vào (1 cho Grayscale, 3 cho RGB).
        n_classes: Số lớp phân đoạn (1 cho Binary segmentation, >1 cho Multi-class).
        bilinear: Sử dụng Bilinear Upsampling thay cho ConvTranspose2d nếu True.
        base_channels: Số lượng kênh cơ sở tại tầng đầu tiên (mặc định 64).
        use_checkpoint: Sử dụng gradient checkpointing để tiết kiệm VRAM nếu True.
    """

    def __init__(
        self,
        n_channels: int = 3,
        n_classes: int = 1,
        bilinear: bool = False,
        base_channels: int = 64,
        use_checkpoint: bool = False,
    ) -> None:
        super().__init__()
        self.n_channels = n_channels
        self.n_classes = n_classes
        self.bilinear = bilinear
        self.base_channels = base_channels
        self.use_checkpoint = use_checkpoint

        factor = 2 if bilinear else 1

        # Encoder (Nhánh trích xuất đặc trưng)
        self.inc = DoubleConv(n_channels, base_channels)
        self.down1 = Down(base_channels, base_channels * 2)
        self.down2 = Down(base_channels * 2, base_channels * 4)
        self.down3 = Down(base_channels * 4, base_channels * 8)
        self.down4 = Down(base_channels * 8, (base_channels * 16) // factor)

        # Decoder (Nhánh khôi phục độ phân giải)
        self.up1 = Up(base_channels * 16, (base_channels * 8) // factor, bilinear)
        self.up2 = Up(base_channels * 8, (base_channels * 4) // factor, bilinear)
        self.up3 = Up(base_channels * 4, (base_channels * 2) // factor, bilinear)
        self.up4 = Up(base_channels * 2, base_channels, bilinear)

        # Output head
        self.outc = OutConv(base_channels, n_classes)

        # Khởi tạo trọng số
        self.init_weights()

    def init_weights(self) -> None:
        """Khởi tạo trọng số mô hình theo phân phối Kaiming Normal."""
        for m in self.modules():
            if isinstance(m, nn.Conv2d):
                nn.init.kaiming_normal_(m.weight, mode="fan_out", nonlinearity="relu")
                if m.bias is not None:
                    nn.init.constant_(m.bias, 0.0)
            elif isinstance(m, nn.BatchNorm2d):
                nn.init.constant_(m.weight, 1.0)
                nn.init.constant_(m.bias, 0.0)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        Forward pass của mạng U-Net.
        Args:
            x: Tensor đầu vào shape (B, n_channels, H, W)
        Returns:
            Logits thô shape (B, n_classes, H, W)
        """
        if self.use_checkpoint and x.requires_grad:
            x1 = checkpoint(self.inc, x, use_reentrant=False)
            x2 = checkpoint(self.down1, x1, use_reentrant=False)
            x3 = checkpoint(self.down2, x2, use_reentrant=False)
            x4 = checkpoint(self.down3, x3, use_reentrant=False)
            x5 = checkpoint(self.down4, x4, use_reentrant=False)

            x = checkpoint(self.up1, x5, x4, use_reentrant=False)
            x = checkpoint(self.up2, x, x3, use_reentrant=False)
            x = checkpoint(self.up3, x, x2, use_reentrant=False)
            x = checkpoint(self.up4, x, x1, use_reentrant=False)
            logits = self.outc(x)
        else:
            x1 = self.inc(x)
            x2 = self.down1(x1)
            x3 = self.down2(x2)
            x4 = self.down3(x3)
            x5 = self.down4(x4)

            x = self.up1(x5, x4)
            x = self.up2(x, x3)
            x = self.up3(x, x2)
            x = self.up4(x, x1)
            logits = self.outc(x)

        return logits


def build_model(cfg: Dict[str, Any]) -> UNet:
    """
    Factory function xây dựng mô hình UNet từ cấu hình dict.
    Args:
        cfg: Dict chứa thông tin cấu hình (nhóm 'model')
    Returns:
        Instance UNet
    """
    model_cfg = cfg.get("model", {})
    return UNet(
        n_channels=model_cfg.get("n_channels", 3),
        n_classes=model_cfg.get("n_classes", 1),
        bilinear=model_cfg.get("bilinear", False),
        base_channels=model_cfg.get("base_channels", 64),
        use_checkpoint=model_cfg.get("use_checkpoint", False),
    )
```

```py
"""
unet_parts.py
-------------
Các khối cấu trúc (building blocks) cơ bản cho mạng U-Net:
- DoubleConv: (Conv3x3 -> BatchNorm2d -> ReLU) x 2
- Down: MaxPool2d(2) -> DoubleConv
- Up: Upsample/ConvTranspose2d -> Padding căn chỉnh shape -> Concat -> DoubleConv
- OutConv: Conv2d 1x1 ra số lượng classes
"""

from typing import Optional
import torch
import torch.nn as nn
import torch.nn.functional as F


class DoubleConv(nn.Module):
    """
    (Convolution => [BN] => ReLU) * 2
    """

    def __init__(
        self,
        in_channels: int,
        out_channels: int,
        mid_channels: Optional[int] = None,
    ) -> None:
        super().__init__()
        if mid_channels is None:
            mid_channels = out_channels

        self.double_conv = nn.Sequential(
            nn.Conv2d(in_channels, mid_channels, kernel_size=3, padding=1, bias=False),
            nn.BatchNorm2d(mid_channels),
            nn.ReLU(inplace=True),
            nn.Conv2d(mid_channels, out_channels, kernel_size=3, padding=1, bias=False),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """Forward pass. Shape: (B, C_in, H, W) -> (B, C_out, H, W)"""
        return self.double_conv(x)


class Down(nn.Module):
    """
    Downscaling với MaxPool2d(2) rồi đi qua DoubleConv
    """

    def __init__(self, in_channels: int, out_channels: int) -> None:
        super().__init__()
        self.maxpool_conv = nn.Sequential(
            nn.MaxPool2d(2),
            DoubleConv(in_channels, out_channels),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """Forward pass. Shape: (B, C_in, H, W) -> (B, C_out, H // 2, W // 2)"""
        return self.maxpool_conv(x)


class Up(nn.Module):
    """
    Upscaling sau đó nối với skip connection và đi qua DoubleConv.
    Hỗ trợ cả bilinear=True và ConvTranspose2d.
    Tự động căn chỉnh kích thước bằng F.pad khi H/W lẻ.
    """

    def __init__(
        self,
        in_channels: int,
        out_channels: int,
        bilinear: bool = True,
    ) -> None:
        super().__init__()

        if bilinear:
            self.up = nn.Upsample(scale_factor=2, mode="bilinear", align_corners=True)
            self.conv = DoubleConv(in_channels, out_channels, in_channels // 2)
        else:
            self.up = nn.ConvTranspose2d(
                in_channels, in_channels // 2, kernel_size=2, stride=2
            )
            self.conv = DoubleConv(in_channels, out_channels)

    def forward(self, x1: torch.Tensor, x2: torch.Tensor) -> torch.Tensor:
        """
        Args:
            x1: Tensor từ tầng dưới cần upsample (B, C1, H1, W1)
            x2: Tensor skip connection từ Encoder (B, C2, H2, W2)
        Returns:
            Tensor sau khi concat và conv (B, out_channels, H2, W2)
        """
        x1 = self.up(x1)

        # Căn chỉnh kích thước nếu có sự chênh lệch do kích thước lẻ (H, W không chia hết cho 2)
        diff_y = x2.size(2) - x1.size(2)
        diff_x = x2.size(3) - x1.size(3)

        # F.pad nhận định dạng: [pad_left, pad_right, pad_top, pad_bottom]
        x1 = F.pad(
            x1,
            [
                diff_x // 2,
                diff_x - diff_x // 2,
                diff_y // 2,
                diff_y - diff_y // 2,
            ],
        )

        # Ghép đặc trưng theo chiều kênh (dim=1)
        x = torch.cat([x2, x1], dim=1)
        return self.conv(x)


class OutConv(nn.Module):
    """
    Lớp tích chập 1x1 ánh xạ kênh đặc trưng về số lượng lớp dự đoán (n_classes).
    """

    def __init__(self, in_channels: int, out_channels: int) -> None:
        super().__init__()
        self.conv = nn.Conv2d(in_channels, out_channels, kernel_size=1)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """Forward pass. Shape: (B, C_in, H, W) -> (B, n_classes, H, W)"""
        return self.conv(x)
```

```py
Inference (suy luận) trên ảnh mới (hỗ trợ cả 1 file đơn lẻ hoặc cả thư mục ảnh):

def get_image_files(input_path: Path, patient: str = None, limit: int = None) -> List[Path]:
    """Lấy danh sách các file ảnh hợp lệ, có thể lọc theo mã bệnh nhân và giới hạn số lượng."""
    if input_path.is_file():
        if input_path.suffix.lower() in VALID_EXTS:
            files = [input_path]
        else:
            raise ValueError(f"Định dạng file không được hỗ trợ: {input_path}")
    elif input_path.is_dir():
        files = [f for f in input_path.iterdir() if f.suffix.lower() in VALID_EXTS]
        if not files:
            raise FileNotFoundError(f"Không tìm thấy file ảnh hợp lệ nào trong: {input_path}")
        files = sorted(files)
    else:
        raise FileNotFoundError(f"Đường dẫn đầu vào không tồn tại: {input_path}")

    # Lọc theo bệnh nhân nếu có yêu cầu
    if patient:
        patient_lower = patient.strip().lower()
        filtered = [f for f in files if patient_lower in f.stem.lower()]
        if not filtered:
            available_samples = [f.stem.split('_')[0] for f in files[:10]]
            raise ValueError(
                f"Không tìm thấy ảnh nào khớp với mã bệnh nhân '{patient}' trong thư mục {input_path}.\n"
                f"Một số mã bệnh nhân có sẵn: {list(dict.fromkeys(available_samples))}"
            )
        files = filtered

    # Giới hạn số lượng mẫu
    if limit is not None and limit > 0:
        files = files[:limit]

    return files

        blended = cv2.addWeighted(disp_orig, 0.7, overlay, 0.3, 0)

        overlay_save_path = overlay_dir / f"{img_file.stem}_overlay.png"
        cv2.imwrite(str(overlay_save_path), blended)

    print(f"\n🎉 Dự đoán hoàn tất! Kết quả được lưu tại: {output_dir}")
    print(f"  - Thư mục Masks    : {mask_dir}")
    print(f"  - Thư mục Overlays : {overlay_dir}")
```

```py
def format_time(seconds: float) -> str:
    """Đổi số giây sang định dạng giờ:phút:giây dễ đọc."""

def load_config_and_override() -> Dict[str, Any]:
    """Đọc file YAML config và cho phép override từ command line args."""
    parser = argparse.ArgumentParser(description="Huấn luyện mô hình U-Net Baseline")
    parser.add_argument(
        "--config",

        default="configs/config.yaml",
        help="Đường dẫn đến file cấu hình yaml",

    args, unknown = parser.parse_known_args()

    config_path = Path(args.config)
    if not config_path.exists():
        raise FileNotFoundError(f"Không tìm thấy file config tại: {config_path}")

    with open(config_path, "r", encoding="utf-8") as f:
        cfg = yaml.safe_load(f)

    # Xử lý các cờ override dạng: --train.batch_size=8 hoặc --checkpoint.resume_path=ckpt.pth
    for arg in unknown:
        if arg.startswith("--") and "=" in arg:
            key, val = arg[2:].split("=", 1)
            # Thử parse kiểu dữ liệu int, float, bool
            if val.lower() == "true":
                parsed_val = True
            elif val.lower() == "false":
                parsed_val = False
            elif val.lower() == "null" or val.lower() == "none":
                parsed_val = None
            else:
                try:
                    parsed_val = int(val)
                except ValueError:
                    try:
                        parsed_val = float(val)
                    except ValueError:
                        parsed_val = val

            # Phân tách nested keys
            keys = key.split(".")
            d = cfg
            for k in keys[:-1]:
                if k not in d or not isinstance(d[k], dict):
                    d[k] = {}
                d = d[k]
            d[keys[-1]] = parsed_val

    return cfg


def train_one_epoch(
    model: nn.Module,
    dataloader: torch.utils.data.DataLoader,
    criterion: nn.Module,
    optimizer: torch.optim.Optimizer,
    scaler: torch.cuda.amp.GradScaler,
    device: torch.device,
    grad_clip: float = 1.0,
    use_amp: bool = True,
) -> float:
    """Huấn luyện mô hình 1 epoch."""
    model.train()
    total_loss = 0.0

    pbar = tqdm(dataloader, desc="[Train]", leave=False)
    for images, masks in pbar:
        images = images.to(device, non_blocking=True)
        masks = masks.to(device, non_blocking=True)

        optimizer.zero_grad()

        with torch.autocast(device_type=device.type, enabled=use_amp and device.type == "cuda"):
            logits = model(images)
            loss = criterion(logits, masks)

        if not torch.isfinite(loss):
            print(f"⚠️ Cảnh báo: Loss không hữu hạn ({loss.item()}), bỏ qua batch.")
            optimizer.zero_grad()
            continue

        if use_amp and device.type == "cuda":
            scaler.scale(loss).backward()
            if grad_clip is not None and grad_clip > 0:
                scaler.unscale_(optimizer)
                torch.nn.utils.clip_grad_norm_(model.parameters(), grad_clip)
            scaler.step(optimizer)
            scaler.update()
        else:
            loss.backward()
            if grad_clip is not None and grad_clip > 0:
                torch.nn.utils.clip_grad_norm_(model.parameters(), grad_clip)
            optimizer.step()

        total_loss += loss.item()
        pbar.set_postfix({"loss": f"{loss.item():.4f}"})

    return total_loss / max(len(dataloader), 1)

        logits = model(images)

        if n_classes == 1:
            preds = (torch.sigmoid(logits) > 0.5).cpu().numpy().astype(np.uint8)
            targets = masks.cpu().numpy().astype(np.uint8)
            for i in range(preds.shape[0]):
                p_i = preds[i, 0]
                t_i = targets[i, 0]
                dice = calculate_dice(p_i, t_i)
                iou = calculate_iou(p_i, t_i)
                tracker.update(dice=dice, iou=iou)
        else:
            preds = torch.argmax(logits, dim=1).cpu().numpy().astype(np.uint8)
            targets = masks.cpu().numpy().astype(np.uint8)
            for i in range(preds.shape[0]):
                p_i = preds[i]
                t_i = targets[i]
                dice = calculate_dice(p_i, t_i)
                iou = calculate_iou(p_i, t_i)
                tracker.update(dice=dice, iou=iou)

    metrics_summary = tracker.summary()
    mean_dice = metrics_summary["dice"][0]
    mean_iou = metrics_summary["iou"][0]
    mean_loss = total_loss / max(len(dataloader), 1)

    return mean_loss, mean_dice, mean_iou


def main() -> None:
    cfg = load_config_and_override()

    # 1. Cố định Seed
    seed = cfg["train"].get("seed", 42)
    set_seed(seed)

    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    print(f"🚀 Sử dụng thiết bị: {device}")

    # 2. Chuẩn bị Dataloaders
    print("📦 Đang nạp dữ liệu...")
    try:
        train_loader, val_loader, test_loader = get_dataloaders(cfg)
        print(f"  - Train samples : {len(train_loader.dataset)} ({len(train_loader)} batches)")
        print(f"  - Val samples   : {len(val_loader.dataset)} ({len(val_loader)} batches)")
        print(f"  - Test samples  : {len(test_loader.dataset)} ({len(test_loader)} batches)")
    except Exception as e:
        import traceback
        print(f"⚠️ Lỗi khi tải dữ liệu: {e}")
        traceback.print_exc()
        print("  Vui lòng đảm bảo cấu trúc data/ đã có ảnh trước khi train thật.")
        return

    # 3. Khởi tạo Mô hình & Hàm mất mát
    model = build_model(cfg).to(device)
    criterion = build_loss(cfg).to(device)

    # 4. Cấu hình Optimizer & Scheduler
    train_cfg = cfg["train"]
    lr = float(train_cfg.get("lr", 1e-3))
    weight_decay = float(train_cfg.get("weight_decay", 1e-4))
    opt_name = train_cfg.get("optimizer", "AdamW")

    if opt_name == "AdamW":
        optimizer = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=weight_decay)
    elif opt_name == "Adam":
        optimizer = torch.optim.Adam(model.parameters(), lr=lr, weight_decay=weight_decay)
    elif opt_name == "SGD":
        optimizer = torch.optim.SGD(model.parameters(), lr=lr, momentum=0.9, weight_decay=weight_decay)
    else:
        raise ValueError(f"Optimizer không được hỗ trợ: {opt_name}")

    epochs = train_cfg.get("epochs", 50)
    sched_name = train_cfg.get("scheduler", "CosineAnnealing")
    min_lr = float(train_cfg.get("min_lr", 1e-5))

    if sched_name == "CosineAnnealing":
        scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
            optimizer, T_max=epochs, eta_min=min_lr
        )
    elif sched_name == "ReduceLROnPlateau":
        scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(
            optimizer, mode="max", factor=0.5, patience=3, min_lr=min_lr
        )
    else:
        scheduler = None

    use_amp = train_cfg.get("amp", True)
    grad_clip = float(train_cfg.get("grad_clip", 1.0))
    try:
        scaler = torch.amp.GradScaler("cuda", enabled=use_amp and device.type == "cuda")
    except Exception:
        scaler = torch.cuda.amp.GradScaler(enabled=use_amp and device.type == "cuda")

    # 5. Checkpoints & Logging setup
    ckpt_cfg = cfg.get("checkpoint", {})
    ckpt_dir = Path(ckpt_cfg.get("dir", "checkpoints"))
    ckpt_dir.mkdir(parents=True, exist_ok=True)

    save_best_metric = ckpt_cfg.get("save_best_metric", "val_dice")
    best_val_score = -1.0 if save_best_metric == "val_dice" else 1e9

    start_epoch = 1
    resume_path = ckpt_cfg.get("resume_path", None)

    # Resume nếu có
    if resume_path and Path(resume_path).exists():
        print(f"🔄 Đang phục hồi trạng thái từ: {resume_path}")
        checkpoint = torch.load(resume_path, map_location=device)
        model.load_state_dict(checkpoint["model_state_dict"])
        optimizer.load_state_dict(checkpoint["optimizer_state_dict"])
        if scheduler and checkpoint.get("scheduler_state_dict"):
            scheduler.load_state_dict(checkpoint["scheduler_state_dict"])
        start_epoch = checkpoint.get("epoch", 0) + 1
        best_val_score = checkpoint.get("best_metric", best_val_score)
        print(f"  -> Tiếp tục từ epoch {start_epoch}")

    log_cfg = cfg.get("logging", {})
    writer = None
    if log_cfg.get("tensorboard", True):
        log_dir = log_cfg.get("log_dir", "runs")
        writer = SummaryWriter(log_dir=log_dir)

    history_csv = ckpt_dir / "history.csv"
    if not history_csv.exists() or start_epoch == 1:
        with open(history_csv, "w", newline="", encoding="utf-8") as f:
            csv_writer = csv.writer(f)
            csv_writer.writerow(["epoch", "train_loss", "val_loss", "val_dice", "val_iou", "lr", "time_sec"])

    patience = train_cfg.get("early_stopping_patience", 10)
    patience_counter = 0

    print(f"\n🚀 Bắt đầu huấn luyện {epochs} Epochs...")

    total_start_time = time.time()
    best_epoch_num = start_epoch

    # 6. Training Loop
    for epoch in range(start_epoch, epochs + 1):
        epoch_start_time = time.time()
        curr_lr = optimizer.param_groups[0]["lr"]

        train_loss = train_one_epoch(
            model=model,
            dataloader=train_loader,
            criterion=criterion,
            optimizer=optimizer,
            scaler=scaler,
            device=device,
            grad_clip=grad_clip,
            use_amp=use_amp,
        )

        val_loss, val_dice, val_iou = validate(
            model=model,
            dataloader=val_loader,
            criterion=criterion,
            device=device,
            n_classes=cfg["model"].get("n_classes", 1),
        )

        epoch_duration = time.time() - epoch_start_time

        # Cập nhật scheduler
        if scheduler:
            if isinstance(scheduler, torch.optim.lr_scheduler.ReduceLROnPlateau):
                scheduler.step(val_dice if save_best_metric == "val_dice" else val_loss)
            else:
                scheduler.step()

        # In kết quả
        print(
            f"Epoch [{epoch:03d}/{epochs:03d}] | "
            f"Train Loss: {train_loss:.4f} | "
            f"Val Loss: {val_loss:.4f} | "
            f"Val Dice: {val_dice:.4f} | "
            f"Val IoU: {val_iou:.4f} | "
            f"Time: {format_time(epoch_duration)} | "
            f"LR: {curr_lr:.6f}"
        )

        # Ghi log TensorBoard
        if writer:
            writer.add_scalar("Loss/Train", train_loss, epoch)
            writer.add_scalar("Loss/Val", val_loss, epoch)
            writer.add_scalar("Metric/Val_Dice", val_dice, epoch)
            writer.add_scalar("Metric/Val_IoU", val_iou, epoch)
            writer.add_scalar("Learning_Rate", curr_lr, epoch)
            writer.add_scalar("Time/Epoch_Seconds", epoch_duration, epoch)

        # Ghi history CSV
        with open(history_csv, "a", newline="", encoding="utf-8") as f:
            csv_writer = csv.writer(f)
            csv_writer.writerow([epoch, train_loss, val_loss, val_dice, val_iou, curr_lr, round(epoch_duration, 2)])

        # Lưu checkpoint: last.pth
        ckpt_data = {
            "epoch": epoch,
            "model_state_dict": model.state_dict(),
            "optimizer_state_dict": optimizer.state_dict(),
            "scheduler_state_dict": scheduler.state_dict() if scheduler else None,
            "best_metric": best_val_score,
            "epoch_time_sec": round(epoch_duration, 2),
            "total_time_sec": round(time.time() - total_start_time, 2),
            "config": cfg,
        }
        torch.save(ckpt_data, ckpt_dir / "last.pth")

        # Kiểm tra best metric
        is_best = False
        if save_best_metric == "val_dice" and val_dice > best_val_score:
            best_val_score = val_dice
            is_best = True
        elif save_best_metric == "val_loss" and val_loss < best_val_score:
            best_val_score = val_loss
            is_best = True

        if is_best:
            patience_counter = 0
            best_epoch_num = epoch
            torch.save(ckpt_data, ckpt_dir / "best.pth")
            print(f"  🌟 Lưu mô hình tốt nhất (best.pth) tại Epoch {epoch:03d} ({save_best_metric}: {best_val_score:.4f})")
        else:
            patience_counter += 1
            if patience_counter >= patience:
                print(f"🛑 Kích hoạt Early Stopping sau {patience} epochs không cải thiện.")
                break

    if writer:
        writer.close()

    total_duration = time.time() - total_start_time
    num_trained = max(1, epoch - start_epoch + 1)
    avg_duration = total_duration / num_trained

    print("\n" + "=" * 65)
    print("✅ Hoàn thành quá trình huấn luyện!")
    print(f"⏱️ Tổng thời gian chạy     : {format_time(total_duration)} ({total_duration:.2f}s)")
    print(f"⏱️ Thời gian TB / Epoch    : {format_time(avg_duration)} ({avg_duration:.2f}s)")
    print(f"🌟 Epoch tốt nhất          : Epoch {best_epoch_num:03d} ({save_best_metric}: {best_val_score:.4f})")
    print(f"📁 Checkpoint tốt nhất     : {ckpt_dir / 'best.pth'}")
    print("=" * 65)

    # Xuất file tổng kết train_summary.json
    summary_data = {
        "start_epoch": start_epoch,
        "end_epoch": epoch,
        "epochs_trained": num_trained,
        "total_time_sec": round(total_duration, 2),
        "total_time_formatted": format_time(total_duration),
        "avg_epoch_time_sec": round(avg_duration, 2),
        "avg_epoch_time_formatted": format_time(avg_duration),
        "best_epoch": best_epoch_num,
        "best_metric_name": save_best_metric,
        "best_metric_value": round(float(best_val_score), 4),
    }
    summary_path = ckpt_dir / "train_summary.json"
    with open(summary_path, "w", encoding="utf-8") as f:
        json.dump(summary_data, f, indent=2, ensure_ascii=False)
    print(f"📄 Báo cáo chi tiết thời gian đã lưu vào: {summary_path}")


if __name__ == "__main__":
    main()
```

```py
"""
dataset.py
----------
Custom PyTorch Dataset cho bài toán phân đoạn ảnh (Semantic Segmentation).
- Tự động ghép cặp ảnh và mask theo tên file (stem)
- Hỗ trợ các định dạng: .png, .jpg, .jpeg, .tif, .tiff, .npy
- Kiểm tra tính toàn vẹn và báo lỗi nếu thiếu cặp
- Hàm factory get_dataloaders(cfg) tạo DataLoader cho train/val/test
"""

import os
from pathlib import Path
from typing import Optional, Callable, Tuple, List, Dict, Any

import cv2
import numpy as np
import torch
from torch.utils.data import Dataset, DataLoader

from .transforms import get_train_transforms, get_val_transforms

VALID_EXTENSIONS = {".png", ".jpg", ".jpeg", ".tif", ".tiff", ".npy"}


class SegmentationDataset(Dataset):
    """
    Dataset cho bài toán Segmentation ghép cặp theo file stem.

    Args:
        root: Thư mục chứa dữ liệu (ví dụ: 'data').
        split: 'train', 'val', hoặc 'test'.
        transform: Callable Albumentations pipeline.
        n_channels: Số kênh ảnh đầu vào (1 hoặc 3).
        n_classes: Số lượng lớp (1 cho nhị phân, >1 cho đa lớp).
    """

    def __init__(
        self,
        root: str,
        split: str = "train",
        transform: Optional[Callable] = None,
        n_channels: int = 3,
        n_classes: int = 1,
        limit_samples: Optional[int] = None,
    ) -> None:
        super().__init__()
        self.root = Path(root)
        self.split = split
        self.transform = transform
        self.n_channels = n_channels
        self.n_classes = n_classes
        self.limit_samples = limit_samples

        images_dir = self.root / split / "images"
        masks_dir = self.root / split / "masks"

        if not images_dir.exists():
            raise FileNotFoundError(f"Không tìm thấy thư mục ảnh: {images_dir}")
        if not masks_dir.exists():
            raise FileNotFoundError(f"Không tìm thấy thư mục mask: {masks_dir}")

        # Quét các file ảnh hợp lệ
        image_files = sorted(
            [f for f in images_dir.iterdir() if f.suffix.lower() in VALID_EXTENSIONS]
        )
        mask_files = sorted(
            [f for f in masks_dir.iterdir() if f.suffix.lower() in VALID_EXTENSIONS]
        )

        # Tạo map theo stem
        mask_map = {f.stem: f for f in mask_files}

        self.samples: List[Tuple[Path, Path]] = []
        missing_masks: List[str] = []

        for img_path in image_files:
            if img_path.stem in mask_map:
                self.samples.append((img_path, mask_map[img_path.stem]))
            else:
                missing_masks.append(img_path.name)

        if missing_masks:
            raise ValueError(
                f"[{split}] Có {len(missing_masks)} ảnh không tìm thấy mask tương ứng! "
                f"Ví dụ: {missing_masks[:5]}"
            )

        if len(self.samples) == 0:
            import warnings
            warnings.warn(
                f"[{split}] Cảnh báo: Thư mục {images_dir} không chứa mẫu dữ liệu nào!"
            )

        # Giới hạn số lượng mẫu nếu có cấu hình limit_samples
        if self.limit_samples is not None and self.limit_samples > 0 and self.limit_samples < len(self.samples):
            import random
            rng = random.Random(42)
            self.samples = rng.sample(self.samples, self.limit_samples)
            print(f"  ⚡ [{split.upper()}] Đã giới hạn mẫu thử nghiệm: {len(self.samples)} mẫu.")

    def __len__(self) -> int:
        return len(self.samples)

    def _load_image(self, path: Path) -> np.ndarray:
        """Đọc file ảnh từ đường dẫn hỗ trợ npy, png, jpg, tif (có cơ chế retry chống nghẽn Drive)."""
        if path.suffix.lower() == ".npy":
            arr = np.load(str(path))
            if arr.ndim == 2:
                arr = arr[:, :, np.newaxis]
            elif arr.ndim == 3 and arr.shape[0] in [1, 3]:
                # Chuyển (C, H, W) -> (H, W, C) cho Albumentations
                arr = np.transpose(arr, (1, 2, 0))
            if self.n_channels == 3 and arr.shape[-1] == 1:
                arr = np.repeat(arr, 3, axis=-1)
            return arr.astype(np.float32)

        # Ảnh chuẩn (png, jpg, tif) kèm retry
        img = None
        for _ in range(3):
            if self.n_channels == 1:
                img = cv2.imread(str(path), cv2.IMREAD_GRAYSCALE)
            else:
                img = cv2.imread(str(path), cv2.IMREAD_COLOR)
            if img is not None:
                break
            import time
            time.sleep(0.1)

        if img is None:
            raise IOError(f"Không thể đọc file ảnh sau 3 lần thử: {path}")

        if self.n_channels == 3:
            img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
        return img.astype(np.float32)

    def _load_mask(self, path: Path) -> np.ndarray:
        """Đọc file mask từ đường dẫn kèm retry."""
        if path.suffix.lower() == ".npy":
            mask = np.load(str(path))
            if mask.ndim == 3 and mask.shape[0] == 1:
                mask = mask.squeeze(0)
            elif mask.ndim == 3 and mask.shape[-1] == 1:
                mask = mask.squeeze(-1)
            return mask

        mask = None
        for _ in range(3):
            mask = cv2.imread(str(path), cv2.IMREAD_GRAYSCALE)
            if mask is not None:
                break
            import time
            time.sleep(0.1)

        if mask is None:
            raise IOError(f"Không thể đọc file mask sau 3 lần thử: {path}")
        return mask

    def __getitem__(self, idx: int) -> Tuple[torch.Tensor, torch.Tensor]:
        img_path, mask_path = self.samples[idx]

        image = self._load_image(img_path)
        mask = self._load_mask(mask_path)

        # Xử lý nhãn nhị phân nếu cần chuẩn hóa về 0 và 1
        if self.n_classes == 1:
            if mask.max() > 1.0:
                mask = (mask > 127).astype(np.float32)
            else:
                mask = (mask > 0.5).astype(np.float32)
        else:
            mask = mask.astype(np.int64)

        # Áp dụng Augmentation nếu có
        if self.transform is not None:
            augmented = self.transform(image=image, mask=mask)
            image = augmented["image"]
            mask = augmented["mask"]

        # Chuyển image thành PyTorch Tensor (C, H, W) float32
        if image.ndim == 2:
            image_tensor = torch.from_numpy(image).unsqueeze(0).float()
        elif image.ndim == 3:
            # (H, W, C) -> (C, H, W)
            image_tensor = torch.from_numpy(image).permute(2, 0, 1).float()
        else:
            raise ValueError(f"Shape ảnh không hợp lệ: {image.shape}")

        # Chuyển mask thành PyTorch Tensor
        if self.n_classes == 1:
            # Mask nhị phân -> shape (1, H, W) float32
            if isinstance(mask, np.ndarray):
                mask_tensor = torch.from_numpy(mask).float()
            else:
                mask_tensor = mask.float()
            if mask_tensor.ndim == 2:
                mask_tensor = mask_tensor.unsqueeze(0)
        else:
            # Mask đa lớp -> shape (H, W) long
            if isinstance(mask, np.ndarray):
                mask_tensor = torch.from_numpy(mask).long()
            else:
                mask_tensor = mask.long()

        return image_tensor, mask_tensor
```

```py
"""
losses.py
---------
Các hàm mất mát (Loss functions) cho bài toán Semantic Segmentation:
- DiceLoss (hỗ trợ cả nhị phân và đa lớp, có smooth epsilon)
- BCEWithLogitsLossWrapper (tự động chuyển CrossEntropy nếu đa lớp)
- FocalLoss (chống mất cân bằng dữ liệu)
- CombinedLoss (kết hợp tuyến tính các hàm loss theo trọng số)
- Factory function build_loss(cfg)
"""

from typing import Dict, Any, Optional
import torch
import torch.nn as nn
import torch.nn.functional as F


class DiceLoss(nn.Module):
    """
    Dice Loss tính trên raw logits.
    Hỗ trợ cả bài toán nhị phân (n_classes = 1) và đa lớp (n_classes > 1).
    """

    def __init__(self, smooth: float = 1e-6) -> None:
        super().__init__()
        self.smooth = smooth

    def forward(self, logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
        """
        Args:
            logits: Tensor (B, C, H, W)
            targets: Tensor (B, 1, H, W) float nếu C=1; hoặc (B, H, W) long nếu C>1
        """
        logits = logits.float()
        targets = targets.float()

        if logits.shape[1] == 1:
            # Nhị phân
            probs = torch.sigmoid(logits)

            intersection = (probs * targets).sum(dim=(2, 3))
            union = probs.sum(dim=(2, 3)) + targets.sum(dim=(2, 3))

            dice = (2.0 * intersection + self.smooth) / (union + self.smooth)
            return 1.0 - dice.mean()
        else:
            # Đa lớp
            probs = F.softmax(logits, dim=1)
            num_classes = logits.shape[1]
            targets_one_hot = F.one_hot(targets.long(), num_classes=num_classes).permute(
                0, 3, 1, 2
            ).float()

            intersection = (probs * targets_one_hot).sum(dim=(2, 3))
            union = probs.sum(dim=(2, 3)) + targets_one_hot.sum(dim=(2, 3))

            dice = (2.0 * intersection + self.smooth) / (union + self.smooth)
            return 1.0 - dice.mean()


class BCEWithLogitsLossWrapper(nn.Module):
    """Wrapper cho BCEWithLogitsLoss (nhị phân) hoặc CrossEntropyLoss (đa lớp)."""

    def __init__(self, pos_weight: Optional[torch.Tensor] = None) -> None:
        super().__init__()
        self.bce = nn.BCEWithLogitsLoss(pos_weight=pos_weight)
        self.ce = nn.CrossEntropyLoss()

    def forward(self, logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
        logits = logits.float()
        if logits.shape[1] == 1:
            return self.bce(logits, targets.float())
        else:
            return self.ce(logits, targets.long())


class FocalLoss(nn.Module):
    """
    Focal Loss nhằm giảm trọng số của các mẫu dễ học và tập trung vào mẫu khó.
    """

    def __init__(self, alpha: float = 0.25, gamma: float = 2.0) -> None:
        super().__init__()
        self.alpha = alpha
        self.gamma = gamma

    def forward(self, logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
        logits = logits.float()
        targets = targets.float()
        if logits.shape[1] == 1:
            bce_loss = F.binary_cross_entropy_with_logits(
                logits, targets, reduction="none"
            )
            p = torch.sigmoid(logits)
            p_t = p * targets + (1 - p) * (1 - targets)
            alpha_t = self.alpha * targets + (1 - self.alpha) * (1 - targets)

            focal_loss = alpha_t * ((1 - p_t) ** self.gamma) * bce_loss
            return focal_loss.mean()
        else:
            ce_loss = F.cross_entropy(logits, targets.long(), reduction="none")
            p_t = torch.exp(-ce_loss)
            focal_loss = ((1 - p_t) ** self.gamma) * ce_loss
            return focal_loss.mean()


class CombinedLoss(nn.Module):
    """
    Kết hợp có trọng số giữa BCE/CE, Dice Loss và Focal Loss.
    """

    def __init__(
        self,
        bce_weight: float = 0.5,
        dice_weight: float = 0.5,
        focal_weight: float = 0.0,
        smooth: float = 1e-6,
    ) -> None:
        super().__init__()
        self.bce_weight = bce_weight
        self.dice_weight = dice_weight
        self.focal_weight = focal_weight

        self.bce = BCEWithLogitsLossWrapper()
        self.dice = DiceLoss(smooth=smooth)
        self.focal = FocalLoss() if focal_weight > 0 else None

    def forward(self, logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
        logits = logits.float()
        targets = targets.float()
        loss = 0.0
        if self.bce_weight > 0:
            loss += self.bce_weight * self.bce(logits, targets)
        if self.dice_weight > 0:
            loss += self.dice_weight * self.dice(logits, targets)
        if self.focal_weight > 0 and self.focal is not None:
            loss += self.focal_weight * self.focal(logits, targets)
        return loss


def build_loss(cfg: Dict[str, Any]) -> nn.Module:
    """
    Factory function khởi tạo loss function từ cấu hình dict.
    """
    loss_cfg = cfg.get("loss", {})
    loss_type = loss_cfg.get("type", "CombinedLoss")

    if loss_type == "DiceLoss":
        return DiceLoss(smooth=loss_cfg.get("smooth", 1e-6))
    elif loss_type in ["BCE", "BCEWithLogitsLoss"]:
        return BCEWithLogitsLossWrapper()
    elif loss_type == "FocalLoss":
        return FocalLoss(
            alpha=loss_cfg.get("alpha", 0.25),
            gamma=loss_cfg.get("gamma", 2.0),
        )
    elif loss_type == "CombinedLoss":
        return CombinedLoss(
            bce_weight=loss_cfg.get("bce_weight", 0.5),
            dice_weight=loss_cfg.get("dice_weight", 0.5),
            focal_weight=loss_cfg.get("focal_weight", 0.0),
            smooth=loss_cfg.get("smooth", 1e-6),
        )
    else:
        raise ValueError(f"Không hỗ trợ loss type: {loss_type}")
```

```py
"""
metrics.py
----------
Các chỉ số đánh giá (Evaluation Metrics) cho phân đoạn ảnh:
- Dice Similarity Coefficient (DSC)
- Intersection over Union (IoU / Jaccard Index)
- 95th Percentile Hausdorff Distance (HD95)
- Class MetricTracker hỗ trợ tính toán và theo dõi theo từng ảnh riêng lẻ
"""

from typing import Dict, Any, Optional, Tuple, List
import numpy as np
from scipy.ndimage import binary_erosion
from scipy.spatial.distance import cdist


def calculate_dice(
    pred: np.ndarray,
    target: np.ndarray,
    smooth: float = 1e-6,
) -> float:
    """
    Tính Dice Coefficient giữa 2 mảng nhị phân nhãn {0, 1}.
    Args:
        pred: Mảng nhị phân dự đoán (H, W)
        target: Mảng nhị phân ground truth (H, W)
    Returns:
        Điểm số Dice [0.0, 1.0]
    """
    pred = pred.astype(bool)
    target = target.astype(bool)

    pred_sum = np.sum(pred)
    target_sum = np.sum(target)

    # Trường hợp cả hai cùng rỗng (không có khối u và dự đoán đúng không có khối u)
    if pred_sum == 0 and target_sum == 0:
        return 1.0
    # Một bên có, một bên không
    if pred_sum == 0 or target_sum == 0:
        return 0.0

    intersection = np.sum(pred & target)
    return float((2.0 * intersection) / (pred_sum + target_sum + smooth))


def calculate_iou(
    pred: np.ndarray,
    target: np.ndarray,
    smooth: float = 1e-6,
) -> float:
    """
    Tính IoU (Jaccard Index) giữa 2 mảng nhị phân.
    """
    pred = pred.astype(bool)
    target = target.astype(bool)

    pred_sum = np.sum(pred)
    target_sum = np.sum(target)

    if pred_sum == 0 and target_sum == 0:
        return 1.0
    if pred_sum == 0 or target_sum == 0:
        return 0.0

    intersection = np.sum(pred & target)
    union = np.sum(pred | target)
    return float((intersection) / (union + smooth))


def _get_surface_points(mask: np.ndarray) -> np.ndarray:
    """Trích xuất tọa độ các pixel đường viền (surface boundary) của mask."""
    if mask.sum() == 0:
        return np.empty((0, 2))
    # Đường viền = Mask trừ đi phần xói mòn (erosion)
    eroded = binary_erosion(mask)
    border = mask ^ eroded
    return np.argwhere(border)


def calculate_hd95(pred: np.ndarray, target: np.ndarray) -> float:
    """
    Tính Hausdorff Distance percentile 95 (HD95).
    Nếu pred hoặc target rỗng hoàn toàn, trả về np.nan theo quy ước.
    """
    pred_bool = pred.astype(bool)
    target_bool = target.astype(bool)

    # Cả hai cùng rỗng
    if pred_bool.sum() == 0 and target_bool.sum() == 0:
        return 0.0

    # Một trong hai rỗng -> Không thể đo khoảng cách biên
    if pred_bool.sum() == 0 or target_bool.sum() == 0:
        return float("nan")

    pred_pts = _get_surface_points(pred_bool)
    target_pts = _get_surface_points(target_bool)

    if len(pred_pts) == 0 or len(target_pts) == 0:
        return float("nan")

    # Khoảng cách euclid 2 chiều
    dists_pred_to_target = cdist(pred_pts, target_pts).min(axis=1)
    dists_target_to_pred = cdist(target_pts, pred_pts).min(axis=1)

    hd95 = max(
        np.percentile(dists_pred_to_target, 95),
        np.percentile(dists_target_to_pred, 95),
    )
    return float(hd95)


class MetricTracker:
    """
    Lớp lưu trữ và theo dõi các chỉ số đánh giá cho từng ảnh trong batch/dataset.
    """

    def __init__(self) -> None:
        self.reset()

    def reset(self) -> None:
        self.dices: List[float] = []
        self.ious: List[float] = []
        self.hd95s: List[float] = []

    def update(
        self,
        dice: float,
        iou: float,
        hd95: Optional[float] = None,
    ) -> None:
        self.dices.append(dice)
        self.ious.append(iou)
        if hd95 is not None and not np.isnan(hd95):
            self.hd95s.append(hd95)

    def summary(self) -> Dict[str, Tuple[float, float]]:
        """
        Trả về dict {metric: (mean, std)}.
        """
        result = {}
        result["dice"] = (
            float(np.mean(self.dices)) if self.dices else 0.0,
            float(np.std(self.dices)) if self.dices else 0.0,
        )
        result["iou"] = (
            float(np.mean(self.ious)) if self.ious else 0.0,
            float(np.std(self.ious)) if self.ious else 0.0,
        )
        result["hd95"] = (
            float(np.mean(self.hd95s)) if self.hd95s else float("nan"),
            float(np.std(self.hd95s)) if self.hd95s else float("nan"),
        )
        return result
```

```py
"""
transforms.py
-------------
Data augmentation và preprocessing cho ảnh và mask sử dụng Albumentations.
Đảm bảo tất cả các phép biến đổi hình học áp dụng đồng thời và đồng nhất lên cả ảnh và mask.
Mask luôn sử dụng phép nội suy cv2.INTER_NEAREST để bảo toàn nhãn nhị phân / số nguyên.
"""

from typing import List, Optional, Dict, Any
import cv2
import albumentations as A


def get_train_transforms(
    image_size: int = 256,
    mean: Optional[List[float]] = None,
    std: Optional[List[float]] = None,
    max_pixel_value: float = 255.0,
    augment_cfg: Optional[Dict[str, Any]] = None,
) -> A.Compose:
    """
    Tạo pipeline Data Augmentation cho tập TRAIN.

    Args:
        image_size: Kích thước cạnh ảnh sau resize (H = W = image_size).
        mean: Danh sách giá trị trung bình kênh để chuẩn hóa (mặc định [0.5, 0.5, 0.5]).
        std: Danh sách độ lệch chuẩn kênh để chuẩn hóa (mặc định [0.5, 0.5, 0.5]).
        max_pixel_value: Giá trị pixel tối đa trước chuẩn hóa (1.0 cho float, 255.0 cho uint8).
        augment_cfg: Dict cấu hình các xác suất / cường độ biến đổi.

    Returns:
        A.Compose pipeline.
    """
    if mean is None:
        mean = [0.5, 0.5, 0.5]
    if std is None:
        std = [0.5, 0.5, 0.5]
    if augment_cfg is None:
        augment_cfg = {}

    hflip_p = augment_cfg.get("hflip_p", 0.5)
    vflip_p = augment_cfg.get("vflip_p", 0.5)
    rotate90_p = augment_cfg.get("rotate90_p", 0.5)
    shift_scale_rotate_p = augment_cfg.get("shift_scale_rotate_p", 0.5)
    brightness_contrast_p = augment_cfg.get("brightness_contrast_p", 0.5)
    elastic_transform_p = augment_cfg.get("elastic_transform_p", 0.0)
    gaussian_noise_p = augment_cfg.get("gaussian_noise_p", 0.0)

    transform_list = [
        A.Resize(
            height=image_size,
            width=image_size,
            interpolation=cv2.INTER_LINEAR,
        )
    ]

    if hflip_p > 0:
        transform_list.append(A.HorizontalFlip(p=hflip_p))
    if vflip_p > 0:
        transform_list.append(A.VerticalFlip(p=vflip_p))
    if rotate90_p > 0:
        transform_list.append(A.RandomRotate90(p=rotate90_p))
    if shift_scale_rotate_p > 0:
        transform_list.append(
            A.ShiftScaleRotate(
                shift_limit=0.0625,
                scale_limit=0.1,
                rotate_limit=15,
                interpolation=cv2.INTER_LINEAR,
                border_mode=cv2.BORDER_CONSTANT,
                p=shift_scale_rotate_p,
            )
        )
    if elastic_transform_p > 0:
        transform_list.append(
            A.ElasticTransform(
                alpha=1,
                sigma=50,
                alpha_affine=50,
                interpolation=cv2.INTER_LINEAR,
                border_mode=cv2.BORDER_CONSTANT,
                p=elastic_transform_p,
            )
        )
    if brightness_contrast_p > 0:
        transform_list.append(
            A.RandomBrightnessContrast(
                brightness_limit=0.2,
                contrast_limit=0.2,
                p=brightness_contrast_p,
            )
        )
    if gaussian_noise_p > 0:
        transform_list.append(A.GaussNoise(var_limit=(10.0, 50.0), p=gaussian_noise_p))

    # Chuẩn hóa
    transform_list.append(
        A.Normalize(
            mean=mean,
            std=std,
            max_pixel_value=max_pixel_value,
        )
    )

    return A.Compose(transform_list)


def get_val_transforms(
    image_size: int = 256,
    mean: Optional[List[float]] = None,
    std: Optional[List[float]] = None,
    max_pixel_value: float = 255.0,
) -> A.Compose:
    """
    Tạo pipeline tiền xử lý cho tập VALIDATION và TEST (chỉ Resize + Normalize).
    """
    if mean is None:
        mean = [0.5, 0.5, 0.5]
    if std is None:
        std = [0.5, 0.5, 0.5]

    return A.Compose(
        [
            A.Resize(
                height=image_size,
                width=image_size,
                interpolation=cv2.INTER_LINEAR,
            ),
            A.Normalize(
                mean=mean,
                std=std,
                max_pixel_value=max_pixel_value,
            ),
        ]
    )
```
